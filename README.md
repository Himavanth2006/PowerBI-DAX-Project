# Power BI DAX Analysis

## Overview

This project focuses on practicing DAX (Data Analysis Expressions) in Power BI using an orders dataset.

The project demonstrates how DAX can be used to create calculated columns, measures, and perform aggregations for sales and profit analysis.

## Tools Used

- Power BI
- DAX

## DAX Concepts Practiced

- Calculated Columns
- Measures
- SUM()
- Row-level calculations
- Aggregations
- Profit calculations
- Order categorization

## Calculations Performed

- Total Orders
- Total Profit
- Profit by Product
- Profit by State
- Orders by State
- Orders by Customer
- Order Category (Small Order / Big Order)

## Project Files

- `PowerBI_DAX_Analysis.pbix` — Power BI file containing the DAX calculations
- `dax_results.png` — Screenshot showing the DAX calculation results
- `data_calculations.png` — Screenshot showing calculated columns and data

## Objective

The objective of this project was to strengthen my understanding of DAX and learn how calculated columns and measures can be used to analyze business data in Power BI.
